PLACE-BASED SOLUTIONS

場所に合わせて、
無理のない対策を。

気になる場所や抱えている不安に合わせて、アイテムを選びましょう。

01 / PASS THROUGH

敷地を横切る人や車が気になる

お悩み / PROBLEM 「いつの間にか、敷地の中を横切られている」

道路との境界が曖昧なオープン外構は、通行人のショートカットに使われたり、角地への車の進入・Uターン場所として入り込まれたりしやすい状態。視線や接触リスクも気になるところ。

解決策 / SOLUTION

このお悩みには

ポールで境界を示し、通り抜けや進入をためらわせる

ガードポールで敷地の境界線を明確にし、物理的・視覚的に通り抜けをブロック。チェーン受け付きタイプなら、不在時や夜間の駐車スペースも開閉式でしっかりガードできる。

02 / SIDE PASSAGE

建物脇の通路に入り込まれるのが心配

お悩み / PROBLEM 「道路からの死角で、誰かが入っても気づきにくい」

建物脇の狭い通路や裏手は道路側から視線が届きやすく、子どもが入り込んだり不審者が身を潜めたりしやすい死角になりがち。勝手口や窓まわりへの接近も不安要素。

解決策 / SOLUTION

このお悩みには

物理的なガードで、侵入の心理的ハードルを上げる

高さ約80cmのガードスタンドを通路の入り口に置くだけで、「ここから先は私有地」と明確に意思表示して侵入をためらわせる。大掛かりな基礎工事不要なため、狭い場所にも手軽に設置可能。

03 / BOUNDARY

道路との境界を示し、侵入を防ぎたい

お悩み / PROBLEM 「境界が曖昧で、ふらっと侵入されないか不安」

高い塀やフェンスで囲うと圧迫感や閉塞感が出る一方、何もないままだと道路と敷地の境界が分かりにくく、悪意のない立ち入りや無断駐輪などを招きやすい。

解決策 / SOLUTION

このお悩みには

空間をゆるやかに仕切り、敷地への侵入を抑止する

ガードフェンスやスタイルポールを配置することで、光や風を通しながら開放感を損なわずに境界をデザイン。空間をゆるやかに仕切ることで、外部からの無断侵入を自然に抑止する。圧迫感を抑えて境界を示し、外部からの侵入を抑止します。

COLUMN / BIKE THEFT

敷地内に置いた自転車の盗難が心配

お悩み / PROBLEM 「オープンな駐輪スペースから持ち去られないか不安」

道路からすぐアクセスできる開放的な駐輪スペースは、出し入れがしやすい反面、通りがかりの第三者からも自転車が見えやすい状態。車の陰や死角になる場所では、鍵をかけていてもそのまま持ち去られるリスクがある。

解決策 / SOLUTION

プラスワン対策

「地球ロック」で自転車の持ち去りを防ぐ

地面に固定されたスタンドと自転車のフレームをワイヤー錠でつなぐ「地球ロック」により、自転車ごとの持ち去りを強力に抑止。スタンドで車体を支えることで風による転倒や傷も防ぎ、駐輪スペースをすっきりと保つ。
